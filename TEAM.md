# Two-Member Engineering Governance

### Member 1: Lead Product Engineer (Frontend & PWA)
- **Primary Responsibilities**:
  - Application Shell, Design System, Responsive layout.
  - Interactive Onboarding Walkthrough and tour lifecycle.
  - PWA compliance (`vite-plugin-pwa`, Manifest, Service worker, Install buttons).
  - Component views: ChatView, MemoryView, KnowledgeView, DocumentsView, SettingsView.
  - Accessibility and light/dark theme aesthetics.

### Member 2: Backend & Intelligence Engineer (Storage & Security)
- **Primary Responsibilities**:
  - Express Server and Google GenAI SDK integration.
  - IndexedDB architecture and transactional migrations.
  - Personal Memory relevance scoring engine and tokenization.
  - Document chunking and indexed text search.
  - Web Crypto AES-256-GCM encryption & integrity checks.
  - Google Drive REST API integration and Firebase OAuth.
  - Unit tests and automated test suites.
